بستہ ماہانہ کارکردگی — Android Studio پروجیکٹ

اہم خصوصیات:
- انٹرنیٹ کے بغیر چلتا ہے۔
- مہینہ اور سال منتخب کرنے پر تاریخ اور دن خودکار بن جاتے ہیں۔
- روزانہ فارم کے 18 عددی خانے، ماہانہ کارکردگی کے خانے، سابقہ ماہ کا تقابل۔
- اسی ڈیوائس میں ریکارڈ محفوظ، پرانے مہینے کھولنے/حذف کرنے کی سہولت۔
- CSV برآمد اور پرنٹ۔

APK بنانے کا طریقہ:
1) کمپیوٹر پر Android Studio اور Android SDK نصب کریں۔
2) Android Studio میں یہ پروجیکٹ فولڈر کھولیں۔
3) Gradle Sync مکمل کریں۔
4) Build > Build Bundle(s) / APK(s) > Build APK(s) منتخب کریں۔
5) APK app/build/outputs/apk/debug/app-debug.apk میں ملے گی۔

نوٹ:
یہ Android Studio کا سورس پروجیکٹ ہے، تیار شدہ APK بائنری نہیں۔ اس ماحول میں Android SDK/Gradle موجود نہ ہونے کی وجہ سے APK کو یہاں کمپائل نہیں کیا جا سکا۔
اصل Excel میں موجود فارمولوں کو بنیاد بنا کر روزانہ کے مجموعے اور تقابلی فیصد شامل کیے گئے ہیں؛ بعض خانوں کے اصل فارمولا/معنی مبہم ہونے کی وجہ سے ادارے کے اصل حساب سے ایک بار تصدیق کر لیں۔
